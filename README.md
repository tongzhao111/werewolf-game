# 三国狼人杀 · 多智能体游戏

基于 [AgentScope 2.0](https://github.com/agentscope-ai/agentscope) 和 DeepSeek 大模型构建的多智能体狼人杀游戏。所有玩家角色由 AI 智能体扮演，每个智能体拥有独立的角色身份、性格特征和推理能力。

## ✨ 核心特性

- **8 人局**：2 狼人 + 1 预言家 + 1 女巫 + 1 守卫 + 3 村民
- **完整角色能力**：狼人击杀、预言家查验、女巫解药/毒药、守卫守护
- **消息驱动协作**：基于 AgentScope 的 Agent 抽象，实现多智能体间的有来有回对话
- **结构化输出**：所有决策（投票、查验、用药）通过 Pydantic 数据模型约束
- **三国人物性格**：刘备仁厚、曹操多疑、诸葛亮睿智……每个人物都有鲜明性格
- **遗言机制**：被淘汰玩家可以留下遗言，影响后续推理
- **容错处理**：单个 Agent API 调用失败时自动降级，不影响全局
- **多局对战 + 日志**：支持批量对战、自动统计胜率、保存每局完整日志

## 🎮 游戏规则

| 角色 | 阵营 | 能力 |
|------|------|------|
| 狼人 | 狼人 | 夜晚协商击杀一名玩家 |
| 预言家 | 好人 | 每晚查验一名玩家的身份（狼人/好人） |
| 女巫 | 好人 | 一瓶解药（救活被杀的玩家）+ 一瓶毒药（毒死一名玩家），各限一次 |
| 守卫 | 好人 | 每晚守护一名玩家，被守护者当晚不会被狼人杀死（不能连续两晚守同一人） |
| 村民 | 好人 | 无特殊能力，靠推理和投票找出狼人 |

**胜利条件**：
- 好人阵营：所有狼人被淘汰
- 狼人阵营：狼人数量 ≥ 好人数量

## 📊 实测数据（20 局样本）

| 指标 | 数值 |
|------|------|
| 好人胜率 | 40.0% |
| 狼人胜率 | 60.0% |
| 平均回合数 | 3.20 |
| 女巫毒对狼 | 2 次 |
| 女巫毒错好人 | 0 次 |
| 守卫成功救人 | 2 次 |

> 注：该胜率接近真人狼人杀的平衡点（真人 9 人局狼人胜率约 58%），说明 AI 的博弈能力已达"人类水平"。

## 🚀 快速开始

### 环境要求

- Python 3.12
- [AgentScope 2.0.8+](https://github.com/agentscope-ai/agentscope)
- DeepSeek API Key

```bash

git clone <your-repo-url>
cd werewolf-game

python -m venv .venv

pip install -r requirements.txt
